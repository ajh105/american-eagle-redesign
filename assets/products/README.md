# Product images

These JPEGs are **American Eagle Outfitters product photos**, downloaded from AE's public image
server by `tools/fetch-ae-images.js` and stored locally so the prototype does not hotlink.
Images © American Eagle Outfitters. They are used only for this non-commercial CSE 463 academic
redesign critique (with the instructor's approval) and are not for reuse or redistribution.
Only the five items in the prototype's catalog are included.
