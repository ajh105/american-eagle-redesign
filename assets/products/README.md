# Product images

These JPEGs are **original renders** generated by `tools/render-product-images.js`. They are not
American Eagle photography. AE's product photos are copyrighted and are not copied into this repository.

## Replacing a render with a real photo

Only use photos you have the right to publish, such as your own photos or images AE has given
permission to use. Save each as a JPEG with exactly the same file name; no code changes are needed.

| File name pattern | What it shows | Size |
|---|---|---|
| `<product>_<color>_front.jpg` | Front view (search tile, gallery 1, bag, drawer, checkout) | 800 × 1024 (4:5) |
| `<product>_<color>_back.jpg` | Back view (gallery 2) | 800 × 1024 |
| `<product>_<color>_detail.jpg` | Waistband or front close-up (gallery 3, color swatch crop) | 800 × 1024 |
| `<product>_<color>_pocket.jpg` | Back pocket close-up (gallery 4) | 800 × 1024 |
| `hero.jpg` | Homepage hero | 1600 × 640 |

Products and colors used: `wide-leg` (`dark-indigo`, `medium-bright-indigo`, `light-vintage`),
`straight` (`dark-indigo`), `curvy` (`medium-bright-indigo`). The scenario item is
`wide-leg_medium-bright-indigo_*.jpg` (style 0437-6331, Medium Bright Indigo).

If you replace any image with a real photo, update the footer text "product images are original renders" in `index.html`.

To regenerate the renders: `node tools/render-product-images.js` (needs Playwright).
